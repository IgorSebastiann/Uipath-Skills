## Documentação por pacote

O portal de atividades usa páginas específicas para:

- overview do domínio ou pacote;
- lista de atividades;
- página de cada atividade;
- project compatibility;
- release notes.

Pesquise dentro de `https://docs.uipath.com/activities/` pelo ID exato do pacote ou pelo nome da atividade. Prefira páginas sob `latest` para estado atual, mas use o seletor de versão quando a pergunta for sobre uma linha LTS específica.

## Regra de evidência

Use a página da atividade para comportamento e propriedades. Use project compatibility para o tipo de projeto. Use release notes para mudanças de uma versão. Use lifecycle para afirmar se a versão está suportada ou associada a uma LTS.

O feed NuGet confirma que uma versão foi publicada, mas não confirma sozinho que ela continua suportada.
